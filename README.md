# Arrows — Побег Стрелок

Android-игра с вращающимся центральным кругом, запуском шаров по касанию, проверкой столкновений и сохранением прогресса. Собственная реализация на Java / Android Canvas. **Это не точная копия данных и механики исходной Unity-игры.** Нельзя утверждать, что 1200 генерируемых уровней совпадают с уровнями референса.

## Версия 0.3.0: полностью без рекламы

- Удалены реклама, Yandex Mobile Ads SDK, рекламные кнопки, рекламные награды и рекламные обработчики.
- Удалены разрешения INTERNET, ACCESS_NETWORK_STATE, VIBRATE (для работы не требуются).
- Название в Android: «Arrows — Побег Стрелок».
- Игровая логика, 1200 процедурных конфигураций, монеты за победы, магазин оформления и локальный прогресс сохранены.
- Игра должна работать полностью офлайн.
- Проект не содержит ключей подписи и не копирует чужую рекламу.

## Сборка

GitHub Actions → Android debug APK → выбрать последнюю успешную сборку → скачайте архив артефакта и установите `app-debug.apk`.
Для локальной сборки: Android SDK 35, JDK 17, Gradle 8.10.2; команда `gradle assembleDebug`.

## Проверка механики

```bash
javac -d /tmp/strelk-smoke app/src/main/java/pro/strelk/game/{LevelFactory,GameEngine}.java tests/EngineSmokeTest.java
java -cp /tmp/strelk-smoke EngineSmokeTest
```

Перед публикацией в RuStore необходимы ручные тесты установки, прохождения уровней и сохранения прогресса на реальном телефоне, а также собственный постоянный ключ подписи.
